JK Multi Gmail MCP

운영자 한 사람이 본인 소유의 여러 Gmail 계정을 Claude Code 같은 로컬 AI 클라이언트에서 사용하기 위한 애플리케이션입니다. 사용자 요청에 따라 Gmail 정보를 가져오고 메일 작업을 실행하는 MCP 연결 도구입니다.

사용 대상
운영자 본인의 Gmail 계정
사용 환경
사용자 컴퓨터의 MCP 서버와 로컬 AI 클라이언트
운영자 연락처
ysmercury@gmail.com

검색과 읽기

요청한 메일을 검색하고 본문·메타데이터를 읽습니다. 결과는 로컬 AI 클라이언트로 전달됩니다.

메일 정리

사용자 요청에 따라 라벨을 관리하고, 메일을 보관하거나 읽음 상태를 변경합니다.

초안과 발송

초안을 작성하고 메일 발송·답장을 처리합니다. 발송·답장 요청은 운영자가 AI 클라이언트에서 매 요청마다 확인한 뒤 도구를 호출해야 합니다. MCP 서버 자체는 발송·답장 도구가 호출되면 별도 확인 없이 발송합니다.

Google 접근 권한과 사용 목적

로컬 애플리케이션은 Google OAuth를 통해 다음 Gmail 권한을 요청합니다.

  • gmail.readonly메일 검색, 본문과 메타데이터 읽기
  • gmail.send운영자가 확인해야 하는 메일 발송과 답장 (서버 자체 확인 단계 없음)
  • gmail.modify초안 작업, 메일에 라벨 적용·제거, 보관 및 읽음 상태 변경
  • gmail.labels라벨 목록 조회

이 웹사이트의 역할

이곳은 정적 앱 정보 안내 사이트입니다. 메일 화면, 로그인 또는 OAuth 연결 기능을 제공하지 않으며, 사이트 방문으로 Gmail 접근 권한이 부여되지 않습니다. 이 사이트에는 메일 데이터가 없습니다.

연결된 메일 내용은 사용자의 AI 클라이언트에서 선택한 AI 제공자에게 전달될 수 있습니다. 로컬 저장과 제공자 처리는 개인정보처리방침에서 확인할 수 있습니다.
