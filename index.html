Different tools.
Clear permissions.

Mailtodo is the work board in JK Multi Gmail MCP. The work board and the MCP connector use separate data paths and permissions.

WINDOWS WORK BOARD

Mailtodo

  • Connect the accounts you choose through Google
  • Encrypted local account, token and candidate storage using Windows CurrentUser DPAPI
  • Full message bodies are excluded from the encrypted work-board store
  • Choose your subscribed AI to draft a reply, then review the recipient and message before sending

Reading uses gmail.readonly; sending a reply additionally requires gmail.send for the chosen account. Review the original sender and message for every send. There is no automatic sending. Fetching is manual; attachments, PDF processing and OCR are not handled.

LOCAL MCP CONNECTOR

JK Multi Gmail MCP

  • Mail search and reading
  • Sending, replies and drafts
  • Message labels, read state and archive
  • Your selected AI client and provider

The existing MCP requests gmail.readonly, gmail.send, gmail.modify and gmail.labels together. These scopes overlap; incremental minimum-per-feature consent is not claimed.

Its separate local SQLite token store is not encrypted. Email data returned to your AI client may be sent to the AI provider you choose. The operator must confirm each send or reply in the AI client before calling the tool. The MCP server itself sends when called, without an additional confirmation step.

Review extracted candidates against the original mail. Invoice tracking does not make payments.

Read the privacy policy ↗
Does this website connect to my Gmail?

This is the public information site. The work board and MCP run on your computer. Visiting this page does not grant Gmail access, and this site contains no personal mail data.

Who is the application for?

It is a personal tool for the operator's own Gmail accounts. The homepage explains the application and its data use; it does not offer public account registration.

How can I remove Google access?

Manage the application's access in your Google account connections. See the privacy policy for the local storage and deletion process.
