Mailtodo

  • 필요한 계정만 Google을 통해 연결
  • 계정·토큰·추출 후보를 Windows CurrentUser DPAPI로 암호화해 로컬에 저장
  • 암호화 업무 저장소에는 메일 본문 전체를 보관하지 않음
  • 선택한 구독 AI로 답장 작성 · 수신자와 본문 확인 후 발송

메일 읽기는 gmail.readonly, 답장 발송은 선택한 계정의 gmail.send 추가 동의를 사용합니다. 매번 원래 발신자와 본문을 확인한 뒤 발송하며 자동 발송하지 않습니다. 메일 가져오기는 직접 실행합니다. 첨부파일·PDF·OCR은 처리하지 않습니다.

로컬 MCP 연결 도구

JK Multi Gmail MCP

  • 메일 검색과 읽기
  • 메일 발송·답장·초안 작성
  • 메일 라벨·읽음 상태·보관 관리
  • 사용자가 선택한 AI 클라이언트와 제공자

기존 MCP는 gmail.readonly, gmail.send, gmail.modify 및 gmail.labels 권한을 한 번에 요청합니다. 권한 사이에는 중복이 있으며, 기능마다 최소 권한만 순차적으로 요청하는 방식은 아닙니다.

별도로 사용하는 로컬 SQLite 토큰 저장소는 암호화되어 있지 않습니다. AI 클라이언트로 전달된 메일 데이터는 사용자가 선택한 AI 제공자에게 전송될 수 있습니다. 운영자는 발송·답장 도구를 호출하기 전에 매번 AI 클라이언트에서 요청을 확인해야 합니다. MCP 서버 자체는 도구가 호출되면 별도의 추가 확인 없이 발송합니다.

추출된 후보는 원문과 대조해 확인해 주세요. 청구서의 진행 상태를 기록해도 실제 결제는 이루어지지 않습니다.

이 홈페이지가 내 Gmail에 연결되나요?

이곳은 앱을 소개하는 공개 홈페이지입니다. 업무 보드와 MCP는 사용자 컴퓨터에서 실행됩니다. 페이지에 접속해도 Gmail 접근 권한이 부여되지 않으며, 개인 메일 데이터도 포함되어 있지 않습니다.

누가 사용하는 앱인가요?

운영자가 본인 소유의 Gmail 계정을 관리하기 위한 개인용 도구입니다. 홈페이지에서는 앱과 데이터 사용 방식을 소개하며, 일반 사용자를 위한 계정 가입은 제공하지 않습니다.

Google 접근 권한은 어떻게 해제하나요?

앱의 접근 권한은 Google 계정의 연결 설정에서 관리할 수 있습니다. 로컬 저장과 삭제 절차는 개인정보처리방침을 확인해 주세요.
